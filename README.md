# Kurage 防災AIチャット (kbousai)

住所か現在地（GPS）を入れて「逃げた方がいい？」「川が氾濫しそう？」「津波は来る？」「台風は直撃する？」と聞くと、
その地点の **ハザード・警報・観測・避難・被害** を1画面に集めて答える防災チャット。

公開: https://kurage.exbridge.jp/kbousai.php/ （heteml の PHP 透過プロキシ → 当社サーバー :18393）

## 設計
- **結論は規則で決める**（`app/judge.py`）。警戒レベルは内閣府「避難情報に関するガイドライン」に合わせ、
  市区町村の避難情報・気象庁の警報（大雨・洪水・土砂・高潮と特別警報）・キキクル（黄2/赤3/紫4/黒5 相当）・津波警報を同じ物差しに載せる。
  雷・強風・波浪・暴風は表示するが段階には数えない
- **AI は言い換えだけ**（`/api/say`、gemma4:12b-it-qat・192.168.0.3・think:false）。`/api/ask` が発行したトークンの事実しか渡さない
  （利用者の任意の文を AI に通さない）。AI が遅い・落ちていても、規則の答えとカードはすぐ出る
- 取れなかった情報は「無い」と言わず「取得できない」と書く
- 台風の境目（暴風警戒域の半径×1.3以内）は「入らない」と言い切らない

## 集める情報（`app/sources.py`）
| 層 | 出典 |
|---|---|
| ハザード | kflood（洪水・内水・高潮）/ khazard（土砂）/ ktsunami（津波浸水想定） |
| 警報 | 気象庁 警報・注意報 r8（kflood 経由）/ 津波警報・注意報 |
| 観測 | 気象庁 アメダス（最寄り雨量観測所）/ キキクルのタイルの色（z10）/ 台風情報（予報円・暴風警戒域を1時間補間） |
| 避難 | kflood（名古屋市・東京都・千葉県・神奈川県・静岡県の発令）/ krefuge（指定緊急避難場所までの徒歩分） |
| 被害 | 全国を機械で読めるデータが無いので、消防庁・自治体へのリンク |

**川の水位は取り込まない。** 国土交通省「川の防災情報」は「ツール等による定期的なデータ収集は…お控えください」と明記している（2026-09-28 確認）。

## 動かす
```
/usr/bin/python3 -m venv .venv && .venv/bin/pip install -r requirements.txt
cp systemd/kbousai.service ~/.config/systemd/user/ && systemctl --user enable --now kbousai
.venv/bin/python -m pytest -q tests        # 規則のテスト
scripts/deploy_proxy.sh                     # heteml へ公開入口を置く
/usr/bin/python3 scripts/shot.py 'http://127.0.0.1:18393/?q=愛知県名古屋市中川区' outputs/shots   # 端末幅で撮って横はみ出しを実測
```
